## Development

You need Node.js and npm. Copy `.env.example` to `.env`, then set your Supabase credentials, `GEMINI_API_KEY`, and (optionally) `SERPAPI_API_KEY`.

```sh
npm install
npm run dev
```

Resume uploads support text-based PDFs, TXT, Markdown, and RTF files. Website extraction reads the provided public HTML URL directly. If a page cannot be fetched, SerpApi can provide matching Google result snippets as a fallback; it is not used as a page-content scraper.
